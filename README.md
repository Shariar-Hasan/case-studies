# Portfolio Case Studies

One folder per product. Each folder has the same structure:

| File | Purpose |
|---|---|
| `README.md` | Portfolio summary: tagline, description, at-a-glance table, tech stack |
| `case-study.md` | Problem, solution, architecture, technical decisions, role placeholder |
| `key-features.md` | Features by module, one bullet each. **Delete what you did not work on.** |
| `architecture.md` | Repo-by-repo breakdown, data model, auth, deployment, diagrams |
| `assets/` | Screenshots and diagrams |

## Before publishing

- Search each folder for `TODO:` and fill in or remove: live URL, status, dates, impact numbers, screenshots, and **My Role & Contributions**.
- Prune `key-features.md` to your own work. Several of these repos have many contributors.
- Drafted from the code, not from you. Confirm business background and product framing, especially in `muslim-bangla-chat` and `muslim-bangla-bibaho`.
